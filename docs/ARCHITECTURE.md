# 羲和 (Xihe) 架构设计文档

## 概述

羲和是一个基于AI的智能化桌面自动化助手，采用现代化的微服务架构，支持多模态交互和广泛的AI提供商集成。

## 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                        羲和桌面应用                          │
├─────────────────────────────────────────────────────────────┤
│  Electron 主进程  │  React 前端  │  悬浮窗  │  设置窗口      │
├─────────────────────────────────────────────────────────────┤
│                    IPC 通信层                               │
├─────────────────────────────────────────────────────────────┤
│  FastAPI 后端服务  │  AI 代理系统  │  桌面自动化引擎        │
├─────────────────────────────────────────────────────────────┤
│  PostgreSQL  │  Redis  │  文件存储  │  日志系统            │
└─────────────────────────────────────────────────────────────┘
```

## 核心组件

### 1. 前端层 (Frontend)

#### Electron 主进程
- **文件**: `frontend/electron/main.js`
- **职责**:
  - 窗口管理（主窗口、悬浮窗、设置窗口）
  - 系统集成（菜单、托盘、通知）
  - 后端服务管理
  - 安全控制

#### React 应用
- **技术栈**: React 18 + Redux Toolkit + React Query
- **主要页面**:
  - 首页 (`HomePage`): 任务概览和快速操作
  - 聊天页 (`ChatPage`): 与AI对话界面
  - 任务页 (`TasksPage`): 任务管理和历史
  - 设置页 (`SettingsPage`): 应用配置

#### 核心组件
- **VoiceInput**: 语音输入组件，支持实时转录
- **WelcomeCard**: 欢迎界面和任务状态显示
- **AIStatus**: AI服务状态监控
- **QuickActions**: 快速操作面板

### 2. 后端层 (Backend)

#### FastAPI 服务
- **文件**: `backend/main.py`
- **特性**:
  - 异步处理
  - 自动API文档
  - 中间件支持
  - 异常处理

#### API 路由
- **认证模块** (`/api/v1/auth`): 用户认证和授权
- **AI代理模块** (`/api/v1/agents`): AI代理管理
- **任务模块** (`/api/v1/tasks`): 任务执行和管理
- **桌面模块** (`/api/v1/desktop`): 桌面操作接口

#### 核心服务
- **AI提供商管理**: 统一管理多个AI服务
- **桌面自动化**: 跨平台桌面操作
- **任务调度**: 异步任务执行
- **状态管理**: 应用状态持久化

### 3. AI代理系统

#### 代理类型
1. **规划代理 (PlannerAgent)**
   - 任务分解和规划
   - 依赖关系分析
   - 风险评估

2. **执行代理 (ExecutorAgent)**
   - 具体操作执行
   - 环境状态分析
   - 操作反馈

3. **分析代理 (AnalyzerAgent)**
   - 环境状态分析
   - UI元素识别
   - 可行性评估

#### 代理通信
- 基于消息的异步通信
- 上下文共享
- 状态同步

### 4. 桌面自动化引擎

#### 操作类型
- **基础操作**: 点击、拖拽、滚动、输入
- **窗口管理**: 聚焦、最小化、关闭
- **应用控制**: 启动、关闭、切换
- **文件操作**: 读取、写入、管理

#### 平台支持
- **Windows**: 基于Win32 API
- **macOS**: 基于AppleScript和系统API
- **Linux**: 基于X11/Wayland

### 5. 数据层

#### PostgreSQL 数据库
- **用户数据**: 用户信息、偏好设置
- **任务数据**: 任务历史、执行记录
- **会话数据**: 聊天记录、上下文信息

#### Redis 缓存
- **会话缓存**: 用户会话状态
- **任务队列**: 异步任务队列
- **临时数据**: 运行时数据缓存

## 部署架构

### 开发环境
```bash
# 后端开发
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload

# 前端开发
cd frontend
npm install
npm run electron-dev
```

### 生产环境
```bash
# 使用Docker Compose
docker-compose up -d

# 或使用Kubernetes
kubectl apply -f k8s/
```

### 监控和日志
- **应用监控**: Prometheus + Grafana
- **日志聚合**: ELK Stack
- **错误追踪**: Sentry
- **性能分析**: APM工具
